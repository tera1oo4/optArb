# Предметная область — опционный арбитраж

## База

- **Call** — право купить базовый актив по страйку K; **Put** — продать. Крипто-опционы на CEX — **европейские** (экспирация только в дату T), cash-settled
- **Moneyness**: ATM ≈ K близко к форварду F; ITM/OTM относительно F
- **Греки**: delta ∂V/∂S, gamma ∂²V/∂S², vega ∂V/∂σ, theta ∂V/∂t, rho ∂V/∂r
- **IV (implied volatility)** — σ, при которой модельная цена = рыночной; считается численно (бисекция/Ньютон с seed от бисекции; защита от неустойчивости на глубоких ITM/OTM)

## Прайсинг

- Крипто-стандарт — **Black-76** (на форвард F), т.к. опционы маржируются в монете/стейбле и F доступен напрямую из perp/futures:
  - `C = D·(F·N(d1) − K·N(d2))`, `P = D·(K·N(−d2) − F·N(−d1))`
  - `d1 = (ln(F/K) + σ²T/2)/(σ√T)`, `d2 = d1 − σ√T`, D — дисконт-фактор (≈1 в крипте)
- Время до экспирации T — в годах, от точного timestamp экспирации (у всех бирж 08:00 UTC — проверять по метаданным!)
- **Все расчёты — decimal/fixed-point** (ADR-0002), не float

## Биржевые конвенции (критично для cross-venue сравнения!)

| Площадка | Котировка премии | Расчёт | Контракт |
|---|---|---|---|
| Deribit | **в монете (BTC/ETH)** | в монете (inverse) | 1 BTC / 1 ETH |
| Binance | USDT | USDT | multiplier из exchangeInfo (≈0.01 BTC) |
| Bybit | USDC | USDC | multiplier из instruments-info (≈0.01 BTC) |
| OKX | USD | USD | multiplier из instruments (≈0.01 BTC) |
| Polymarket | USDC за share (0–1) | USDC, payoff 0/1 | 1 share = 1 USDC при YES |

- **Никогда не сравнивать цены «как есть»**: приводить к USD-нотионалу на единицу базового актива через текущий индекс
- Мультипликаторы/тики — **только из instruments-API при старте** (ADR-0003); значения выше ориентировочные
- Индексы-источники у бирж разные (свои composite-индексы; Polymarket — источник из правил рынка, часто Chainlink/конкретная биржа) → basis-риск учитывать в edge

## Put-call parity (европейские)

`C − P = D·(F − K)`

- Проверяется внутри биржи (одинаковые K, T) и между биржами (после USD-нормализации и учёта разных индексов/комиссий)
- Нарушение → синтетический форвард vs реальный: buy C + sell P + sell F (или обратно)
- Условие безарбитражности поверхности: butterfly ≥ 0 (выпуклость по K), calendar-монотонность по T

## Цифровые (binary) опционы и Polymarket

- Цифровой колл платит 1, если S_T > K. Цена ≈ риск-нейтральная `P(S_T > K) = N(d2)` (Black-76)
- **Связь с ванилью:** `DigitalCall ≈ −∂C/∂K` — реплицируется **call-spread**: buy C(K−ε) + sell C(K+ε), нотионал 1/(2ε)
- Polymarket-рынок «BTC > X к дате D»: цена YES = implied P(S_T > X). Сравнивать с:
  1. `N(d2)` из IV-поверхности CEX (модельная оценка)
  2. Стоимостью репликации call-spread на Deribit/Bybit/OKX/Binance (торгуемая оценка)
- Сигнал: |YES − replica| > edge-порог (комиссии + spread ширины 2ε + settlement-risk premium)
- **Settlement-риск (ADR-0006):** источник цены и момент фиксации в правилах рынка могут отличаться от индекса хеджа; UMA-резолюция может оспариваться → отдельный лимит номинала
- YES + NO ≠ 1: mint (1 USDC → 1 YES + 1 NO через CTF `split`) / merge — арбитраж без рыночного риска, но с gas/операционкой (v1: полуручной)

## Детекторы v1 (ADR-0001)

1. **Cross-venue same-instrument**: bid_A > ask_B после нормализации валют/мультипликаторов, комиссий и трансферных издержек
2. **Parity**: |C − P − (F − K)| > порог
3. **IV/skew**: IV одинаковых (K, T) между биржами; risk-reversal (IV(K+) − IV(K−)), butterfly
4. **Calendar**: IV(T1) vs IV(T2) при одинаковой moneyness, нарушение монотонности variance
5. **Digital-vs-vanilla**: Polymarket YES vs N(d2)/call-spread (выше)
6. **YES+NO**: отклонение от 1 на Polymarket

Общие фильтры: max age книги (stale → нет сигнала), min ликвидность на обеих ногах, edge ≥ fees + slippage + risk-premium (ADR-0006).

## Полезные константы/факты

- Экспирация крипто-опционов на CEX обычно **08:00 UTC** (ежедневные/недельные/месячные/квартальные) — точное время из метаданных
- Deribit — основной источник IV-поверхности рынка (макс. ликвидность); расхождения alt-бирж с Deribit-улыбкой — главный источник skew-сигналов
- Дисконтирование в крипте часто пренебрежимо (D≈1), но при длинных T учитывать funding/staking-ставку единообразно между ногами
